# OpsPilot PRD

## Objective
Reduce customer cloud spend by 20-40% while preserving SLOs through policy-aware automation.

## Users
- Founder/CTO
- Platform engineering teams
- FinOps stakeholders

## Key jobs to be done
1. Find high-confidence savings opportunities quickly.
2. Execute optimizations safely with approvals and rollback.
3. Prove realized savings with finance-grade attribution.

## Core product loops
- Connect cloud systems -> ingest telemetry -> generate opportunities.
- Approve action -> execute -> monitor impact -> record savings.
- Learn from outcomes -> improve ranking and automation quality.
